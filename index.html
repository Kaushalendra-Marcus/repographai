04 · How it works

Zero → understanding
in four steps

The entire pipeline runs locally. The only external call is to the AI provider you choose.

01

Scan the workspace

Reads all source files. Skips node_modules, dist, lockfiles, minified & generated code.

02

Build the dependency graph

Extracts every import, resolves relative & alias paths into a node-edge map.

03

Generate AI summaries

Batched calls to your provider. Repo overview, architecture, tech stack, per-file docs.

04

Ask anything

Q&A agent with full graph + summary context. Multi-turn with history.

09 · Installation

Up and running in 3 steps

STEP 01

Install the extension

Search “RepoGraph AI” in Extensions and click Install — or paste this in VS Code:

ext install kaushalendra.repograph-ai
STEP 02

Add your API key

Open the RepoGraph panel → Settings → pick a provider → paste key. Start free with Groq.

Get a free Groq key →
STEP 03

Analyze your workspace

Open a project → Analyze tab → Analyze Workspace. Graph ready in 1–2 min.
